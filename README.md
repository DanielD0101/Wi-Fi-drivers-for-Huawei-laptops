# Wi-Fi-драйвера для ноутбуков Huawei

Всем привет! 👋

Создал этот репозиторий, чтобы разместить здесь драйвера для ноутбуков Huawei, поскольку их довольно сложно найти.

Собрана вот такая вот неплохая коллекция драйверов. По возможности буду дополнять список.
